# Syllabus alignment and evidence

The pasted 12-week sequence is the scope. Each week retains 2 concept hours and 2 guided-practice hours. Core labs use prepared, fictional data and no paid API or GPU.

| Week | Outcomes | Required evidence and implementation |
|---|---|---|
| 1 | LO1, LO4 | Ten-case baseline plus two prepared prompt replays; distinguish replay from live variability. |
| 2 | LO1, LO2 | VAE and GAN diagrams, supplied train/validation curve, z change and two toy output images. |
| 3 | LO1, LO2 | Visible denoising stages and a shared two-output review checklist, with consent discussion. |
| 4 | LO1, LO2 | Worked softmax/mask, labelled attention view, and model-role worksheet. |
| 5 | LO4, LO5 | Before/after extraction prompt and ten records including a missing field; schema and source checks. |
| 6 | LO4, LO5 | Five versioned policies, ten retrieval queries, keyword/synonym comparison and a supplied-vector example. |
| 7 | LO4, LO5 | Actual k=1 versus k=2 comparison on 20 cases; ten separate cases in instructor_only/. |
| 8 | LO4, LO5 | Read-only calculator, blocked arguments, a mock approval gate and an audit record. |
| 9 | LO3, LO4 | Supplied base/prompted/tuned scores on separate sets plus sample output evidence. |
| 10 | LO2, LO4 | Synthetic invoice visual, source-linked transcription and independent total calculation. |
| 11 | LO4, LO5 | Actual missing-source, invalid-input, privacy-trace, access-regression and rollback checks. |
| 12 | LO1–LO5 | Integrated success/no-answer/access demonstration and matched baseline examples. |

## Teaching boundaries

The image, VAE/GAN, denoising, semantic-vector and fine-tuning activities are prepared classroom illustrations. They do not claim live model training, learned-embedding benchmarks, OCR accuracy or production deployment. Optional linked vendor implementations can extend them. The core RAG application extracts source text; it does not invoke an LLM.

The final question file includes expected answers for the teacher. Keep it out of the student handout. All practice questions are original exercises, not official exam questions.
